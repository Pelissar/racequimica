Deploy

Configuração para Netlify e Supabase

Netlify

Use `npm run build` e publique a pasta raiz. O `netlify.toml` redireciona `/api/*` para Functions.

Supabase

Crie as tabelas do arquivo `supabase/schema.sql` e o bucket público `racequimica` para imagens.

Variáveis

Configure `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, `ADMIN_USER`, `ADMIN_PASSWORD` e `SESSION_SECRET` no Netlify.
